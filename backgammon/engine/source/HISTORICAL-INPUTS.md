# Historical native experiment inputs

`fullgame-native-v1-inputs.tar.gz` preserves the six exact build inputs used by the completed full-game studies, from repository commit `9f43bc5`. Its SHA-256 is `bdca1a199bf36ce3e74f51c25eb7d5027bdd3ecd8e638f8f7cfbbce0c5a01670`.

The historical plan hashes still validate these bytes. When a current builder changes, the validator checks the archived input against the original recorded hash; it never substitutes a new source hash or weakens the integrity check. The GNUbg source archives, weights and databases retain their separate recorded hashes. These inputs and their patches are GPL-3.0-or-later.
