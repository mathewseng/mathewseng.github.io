# Review action color options

The editable checker-review interaction and Analysis loss-band colors do not depend on the chosen action palette. Option 1 is the current default. The conversation preview shows all ten options, with a selectable EV-loss example.

Each row lists Hint, Play best, Reset and Play anyway hues. Actual button surfaces use a restrained tint mixed into the active skin; labels retain high contrast.
