# redesign/standalone-fixed

This branch is based on `redesign/microtonal-cards`. It holds the fixes for the independent review of that branch
(Card Table Workshop `/cards/` and Microtonal Lab `/microtonal-lab/`). Blackjack Strategy Lab and the Dice report
were not part of the review and are unchanged. The family changelog is `redesign-microtonal-cards.md`.

## Review fixes

| Sev | Finding | What was done |
| --- | --- | --- |
| P1 | Space stopped slapping after a mouse click on a card or panel button (Slapjack, Ratscrew) | `cards/app.js` records whether focus last came from a pointer press or from the keyboard (Tab, arrows, Home, End). A card or button that a pointer focused claims nothing: Space falls through to the slap, and a pointer-focused card no longer becomes the keyboard card. Keyboard-focused cards and buttons keep their Space and Enter, and menu items always keep theirs. `:focus-visible` could not be used, because Chromium turns it on for the focused element at keydown. Verified at 1440x900 in Slapjack. Click Flip, then press Space: it slaps ("slapped wrong and burns a card"), with no second flip. Click a seat card, then press Space: it slaps. Tab to a card, then Space: the card is selected. Tab to a macro, then Space: the macro runs. |
| P2 | Pulse steppers lost keyboard focus after every press | `renderPulseSteps()` updates each `<output>` value and the `.active` step in place when the pattern length is unchanged. It rebuilds the markup only when the length changes. After Enter, or after a click on a stepper, focus stays on that button. |
| P2 | Panel controls under 44px on touch and under 36px on a fine pointer | Removed the inline `min-height:26px` from the bet, Transfer amount and Starting stack inputs and from the score custom input. The coarse rules now cover score-sheet inputs, Players name and team inputs, step fields, custom-card rows, phase and template chips, the evaluator picker and the custom-cards summary. The deck ranks and the hyper-geometric target ranks and suits use `.ct-pick` (30px wide on a fine pointer, 44px on a coarse one). Two scoring `.check` labels lost an inline `min-height:32px` that beat the kit rule. Every pane measures 0 targets under 44px at 375x812 and 844x390 with touch. |
| P2 | `#devJson` rendered at 11.5px | The inline font is gone. `#devJson`, the share-link textarea and the custom-card import textarea use `.ct-code` (`--font-mono`, `--t-sm`, and 1rem with 44px on coarse pointers). |
| P3 | `touch-action: pan-x` on keys blocked vertical scrolling | Keys now use `touch-action: pan-x pan-y`, so the landscape Play view scrolls from a key. Pinch and double-tap zoom stay off on the instrument. This deviates from the brief's `pan-x`: the grid fits the panel width at 320, 375 and 844, so `pan-x` only blocked the vertical scroll. A drag that scrolls still cancels the held note (`pointercancel`), as before. |
| P3 | Group tool buttons overflowed on phones; every "Here" was accent-filled | "Here" is a secondary button (accent border, `--accent-soft` fill, felt ink) everywhere. On phones it is a 44px icon, and the word stays in the DOM for screen readers and the title. `.zone-tools` wraps instead of spilling past the group. |
| P3 | Desktop clipping below 1440x900 | Command fields wrap instead of shrinking below 6.5rem, so 1366x768 shows "Root frequency", 261.63 and Triangle in full, and 1440x900 keeps one row. From 900 to 1279px, keys take 3px side padding and the readout values use `--t-sm`, so the key labels and the cents readout fit at 1024x768. At heights of 860px or less, the readout body scrolls instead of clipping the pulse steps and tempo. At heights of 760px or less, the scope canvas fits its row (`min-height: 0`), the overlay drops its "Active preset" kicker and tightens its meters, and the whole pitch map shows. "Load tuning" is sticky at the bottom of the scrolling builder form. A Playwright check at 1440x900, 1366x768, 1280x720 and 1024x768 (Play, and Builder with a List error) found no clipped labels, inputs, key text or readouts, and "Load tuning" was hit-testable. |
| P3 | The guest phone topbar shrank the page name to "C" | In a room on phones (`#roomBtn` not `data-state="local"`), undo and redo are hidden from the topbar. The compact More menu gains Undo and Redo items while online. This small logic change is needed for the finding: the same `undo()`/`redo()` run, and they toast "Nothing to undo" when empty. The crumb now reads "Card Table …" at 375x812 as a guest. |
| P3 | View tabs have no tabpanels; the one-link tool nav repeats the page name | Not changed. `shared/tabs.js` treats `aria-controls` as a single panel id and sets `hidden` on that element when its tab is inactive. Tunings and Builder are single panes that stay visible in every view on desktop, so a single-id `aria-controls` would hide them. A space-separated list for Play and Scope alone would be inconsistent. Changing `tabs.js` is outside this branch. The one-link `.tool-nav` is the convention for every tool page (prompt non-negotiable 4), so it stays until the integrator decides about single-tool families. |
| P3 | Cards CSS grew from 1018 to 4164 lines; WIP commits had no notes | Not rewritten: halving the Cards stylesheet is a rewrite well beyond a review fix, and history cannot be amended without a rebase. For the record, 9555f40 (WIP) is the Card Table Workshop step 4 restyle: `cards/index.html` shell (topbar, crumbs, tool-nav, tool-head, skip link, live regions), `cards/app.js` markup moved to kit classes, and `cards/styles.css` rewritten on tokens (+4982/-1213 lines incl. app.js). 3a6fc82 (WIP) is `cards/app.js` only: roving tabindex on cards, the zone menu keyboard model and the guest locks (+143/-34). The `drawTuning` overlay read (two `getBoundingClientRect` calls per frame on clean layout) and the print CSS string in `cards/app.js` stay deferred as nits. |
